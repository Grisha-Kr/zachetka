# Моя зачётка

Веб-приложение для учёта учёбы: учебные заведения, предметы, задания со статусами и файлами, расписание сессий, дипломные работы с планом, заметками и файлами. Работает в браузере на компьютере и телефоне, ставится на экран как приложение. У каждого пользователя свой аккаунт, новые пользователи регистрируются по приглашению.

Устроено просто: одна программа [PocketBase](https://pocketbase.io) (база данных, файлы, вход, панель администратора) плюс страницы приложения из папки `pb_public`.

```
pb_public/       интерфейс приложения (HTML, CSS, JS, значки)
pb_migrations/   структура базы и правила доступа
pb_hooks/        приглашения, первый администратор, лимит места на файлы
deploy/          установка и обновление на сервере
```

## Установка на сервер

### Что нужно заранее

1. **Сервер (VPS)** с Ubuntu 24.04, минимум 1 ядро и 1 ГБ памяти (на несколько приложений лучше 2 ядра и 4 ГБ). После оплаты хостинг присылает IP-адрес и пароль root.
2. **Домен**, например `grishaweb.ru`. Приложение будет жить на поддомене: `zachetka.grishaweb.ru`.
3. **A-запись поддомена**: в настройках DNS домена добавьте поддомен `zachetka` с записью типа `A`, значение = IP-адрес сервера. Подождите 15–60 минут, пока запись разойдётся.

На одном сервере может работать несколько приложений: каждое на своём поддомене (`zachetka.`, `greek.` и так далее). Запросы принимает программа Caddy, сама получает сертификаты https и направляет каждый адрес в своё приложение.

### Подключение к серверу

На Mac откройте программу «Терминал», на Windows «PowerShell», и введите (подставьте свой IP):

```
ssh root@123.45.67.89
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`, затем введите пароль root из письма хостинга. Пароль при вводе не отображается, это нормально.

### Установка одной командой

Подставьте свой адрес, почту и имя:

```
curl -fsSL https://raw.githubusercontent.com/Grisha-Kr/zachetka/main/deploy/install.sh | bash -s -- zachetka.grishaweb.ru me@yandex.ru "Иван Иванов"
```

Скрипт сам:
- проверит, что адрес указывает на сервер;
- установит Caddy, скачает код и PocketBase;
- включит автозапуск приложения и защищённое соединение https (сертификат Let's Encrypt Caddy получает автоматически);
- откроет в брандмауэре только нужные порты;
- создаст вход в панель администратора и покажет пароль. **Сохраните его.**

### Первый вход

**Сразу после установки** откройте `https://zachetka.grishaweb.ru` (ваш адрес) и создайте аккаунт. Первый зарегистрированный пользователь становится администратором приложения; остальные смогут зарегистрироваться только по вашему приглашению.

## Приглашения

«Профиль» (значок человека справа вверху) → «Приглашения». Укажите, для кого приглашение и сколько человек может по нему зарегистрироваться, нажмите «Создать приглашение». Ссылка скопируется сама, её можно переслать в мессенджере. Человек откроет ссылку, код подставится автоматически.

## Почта для восстановления пароля

Без этой настройки кнопка «Забыли пароль?» не отправит письмо. Подойдёт Яндекс Почта:

1. В Яндекс ID: «Безопасность» → «Пароли приложений» → создайте пароль для почты.
2. Откройте панель `https://zachetka.grishaweb.ru/_/`, войдите с данными из установки.
3. «Settings» (настройки) → «Mail settings» (почта):
   - Sender address (адрес отправителя): ваш адрес на Яндексе;
   - включите «Use SMTP mail server» (использовать SMTP-сервер);
   - SMTP server host: `smtp.yandex.ru`, Port: `465`, TLS: включено;
   - Username: ваш адрес на Яндексе, Password: пароль приложения из шага 1.
4. Нажмите «Send test email» (отправить тестовое письмо) и проверьте, что оно пришло.

## Установка на телефон и ноутбук

- **iPhone** (Safari): откройте сайт → «Поделиться» → «На экран „Домой“».
- **Android** (Chrome): меню из трёх точек → «Установить приложение» или «Добавить на главный экран».
- **Ноутбук** (Chrome, Edge, Яндекс Браузер): значок установки в адресной строке справа.

## Перенос данных

«Профиль» → «Резервная копия и перенос» → «Загрузить копию». Принимается архив `.zip`, сделанный кнопкой «Скачать копию» (в нём записи и файлы), или архив переноса из прежней версии сайта. Записи добавляются к существующим, поэтому одну и ту же копию загружайте один раз.

## Резервные копии

- Сервер сам делает копию базы каждый день в 3:00 и хранит 14 последних. Скачать или восстановить: панель `/_/` → «Settings» → «Backups».
- Эти копии лежат на том же сервере. Для надёжности включите резервное копирование у хостинга и иногда скачивайте себе копию через «Профиль» → «Скачать копию».

## Обновление

Когда в репозитории появилась новая версия, подключитесь к серверу и выполните:

```
bash /opt/zachetka/src/deploy/update.sh
```

Перед обновлением скрипт сохраняет копию базы в `/opt/zachetka/pb_data/backups`.

Чтобы обновить сам PocketBase, поменяйте `PB_VERSION` в `deploy/install.sh` и запустите установку ещё раз с теми же параметрами. Перед этим прочитайте заметки к выпуску: до версии 1.0 в PocketBase бывают несовместимые изменения.

## Если что-то не работает

```
systemctl status zachetka          # работает ли приложение
journalctl -u zachetka -n 50       # последние сообщения и ошибки
systemctl restart zachetka         # перезапуск
systemctl status caddy             # работает ли Caddy (https и адреса)
journalctl -u caddy -n 50          # ошибки получения сертификата
```

Если у кого-то из пользователей сайт не открывается (сброс соединения или бесконечная загрузка), а у остальных работает, это может быть обрыв защищённого соединения по дороге у провайдера. Поэтому на сервере уже включён только TLS 1.2 и выключен HTTP/3. Такому пользователю можно временно посоветовать браузер Firefox.

Настройки сервера лежат в `/opt/zachetka/zachetka.env`:
- `USER_QUOTA_MB` — сколько мегабайт файлов можно хранить одному пользователю (по умолчанию 500);
- `OWNER_NAME`, `CONTACT_EMAIL` — данные оператора для политики конфиденциальности;
- `APP_TZ_OFFSET` — часовой пояс в часах от UTC, по нему нейросеть понимает, какое сегодня число (по умолчанию 10, Хабаровск).

## Подключение нейросетей

В «Профиль» → «Нейросети» есть адрес `https://АДРЕС/mcp` и инструкции для ChatGPT, Claude и Perplexity. Нейросеть подключается через окно входа зачётки с кнопкой «Разрешить». Она может читать, добавлять и менять записи пользователя, удалять не может. Подключения видны там же, кнопка «Отключить» сразу закрывает доступ.

После правки выполните `systemctl restart zachetka`.

## Персональные данные

Приложение хранит почту, имя, записи и файлы пользователей на вашем сервере в России. При регистрации пользователь даёт согласие на обработку данных, страница политики: `/privacy.html`. Если приложением будут пользоваться не только знакомые, уточните у юриста, нужно ли уведомлять Роскомнадзор об обработке персональных данных.

## Разработка у себя на компьютере

```
./pocketbase serve --publicDir pb_public --hooksDir pb_hooks --migrationsDir pb_migrations
```

Приложение откроется на `http://127.0.0.1:8090`, панель на `http://127.0.0.1:8090/_/`.
